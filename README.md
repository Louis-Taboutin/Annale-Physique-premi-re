## Déployer sur Vercel depuis GitHub

1. Va sur [github.com/new](https://github.com/new) et crée un nouveau repo
2. Clique **"uploading an existing file"**
3. Glisse **tous les fichiers** de ce zip (pas le zip lui-même) dans la zone
4. Commit
5. Va sur [vercel.com/new](https://vercel.com/new) → Import ton repo → **Deploy**

C'est en ligne.
